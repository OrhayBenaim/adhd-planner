# Mascot prompt trial 03 — sparse contour drawing

Status: preview for user review; not approved for Figma or the app.

Reference: `apps/mobile/assets/mascot/dog-wave.png` only.

## Correction to the previous analysis

The original has detailed shapes but sparse marks. Long irregular tufts describe the silhouette; widely spaced fine curves describe the interior. Previous instructions about dense fur detail produced too many marks and heavier rendering. The primary reference has mostly unfilled outlined eyes and nose, no facial shading, and large open areas. Preserve those features rather than adding realism or simplifying the dog into rounded puppy shapes.

## Exact test prompt

Edit the attached original mascot. This is a restrained pose edit, not a new interpretation or restyling.

Keep the original head and face unchanged: the same outlined circular eyes with unfilled interiors, small outlined nose, two muzzle lobes, whisker curves, open smiling mouth, ear shape and swept forehead. Preserve the exact head-to-body proportions, narrow seated body and curled tail.

ONLY CHANGE: lower the waving front paw so both front paws rest naturally on the ground in front of the seated dog. Keep the original expression and everything else as close to the original as possible. Four limbs total, naturally occluded.

Match the source drawing literally:
- Very fine, light black contour lines, mostly uniform hairline thickness.
- Sparse long smooth interior fur curves with generous empty space between them.
- Irregular pointed fur silhouette with selective small tufts.
- Broad open, unfilled areas on the forehead, cheeks, ears, chest and body.
- The same flat, lightly cartooned look; no added realism and no more baby-like proportions.
- The existing flat pale pink and blue graphic accent shapes remain behind the linework.

Do not add fur texture, extra strands, short hatch marks, crosshatching, stippling, black-filled eyes or nose, highlights, bold outlines, shadow, glow, gradients or dimensional rendering. Do not make a detailed ink engraving. The character's detail comes from its SHAPES, not from dense marks.

Keep the original landscape 3:2 composition and scale, with the full dog visible. Output actual transparency, including the open areas of the original line drawing; no visible checkerboard or background panel.

## Review gate

Generate one controlled pose variation and compare at the same size with the original. Ask for user approval before applying artwork to Figma. Refine the prompt first if face shape, line weight, mark density or cartoon proportions drift. The intended scene corrections remain pending until this style test is approved.
