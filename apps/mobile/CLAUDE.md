# CLAUDE.md — Lullio Mobile

## Brand Color Palette

Always use these brand colors for UI elements (backgrounds, accents, chart bars, highlights). Do not introduce arbitrary colors — derive tints/shades from these.

| Name | Hex | Usage |
|------|-----|-------|
| Pink Orchid | `#cdb4db` | Lavender-pink accent, card backgrounds, chart bars |
| Pastel Petal | `#ffc8dd` | Blush accent, card backgrounds, chart bars |
| Blush Pop | `#ffafcc` | Pink accent, card backgrounds, chart bars |
| Icy Blue | `#bde0fe` | Blue accent, card backgrounds, chart bars |

For lighter card backgrounds, use NativeWind opacity modifiers (e.g., `bg-[#bde0fe]/20`).

### Text Colors

| Name | Hex | Usage |
|------|-----|-------|
| Primary Text | `#0A0A0A` | Headings, values, bold text |
| Sub Text | `#6A7282` | Labels, descriptions, muted text |
